# Journal conventions for high-impact venues

**Read this as a map, not as a rulebook.** Limits change between revisions of the author
guidelines. Every number below is a *typical* value recorded to plan the draft; confirm each one
against the live guidelines for the specific journal and article type before submission, and say so
to the user when you have not seen the current guidelines.

## Nature and the Nature family

| Element | Typical convention |
|---|---|
| Order in the online-first article | Title → Abstract → main text (no separate Introduction heading in the printed format) → References → figure legends → Methods → data/code availability → acknowledgements |
| Abstract | One unreferenced paragraph, ~200 words; no citations, no undefined abbreviations |
| Main text | Tight word budget (a few thousand words); the detailed material belongs in Methods |
| Display items | A small number of main figures/tables; additional items become Extended Data figures |
| References | Numeric superscript in citation order; a combined reference list across the paper |
| Methods | Placed after the reference list in the online format; often with Life-Sciences Reporting Summary |
| Figure legends | Begin with a bold title sentence, then the explanation; figure letters lower case |
| Reporting | Life Sciences Reporting Summary, plus a data availability statement and a code availability statement where code was written |

Nature-family research journals (Nature Genetics, Nature Methods, Nature Communications, …) reuse
most of this structure but tune word counts, abstract length and the number of display items.
Nature Communications has no length restriction on the main text in the way *Nature* does.

## Science

| Element | Typical convention |
|---|---|
| Abstract | A single self-contained paragraph; readable by a scientist outside the subfield |
| Structure | Introduction → Results → Discussion, with Materials and Methods at the end |
| References | Numbered in citation order, list restricted to cited works only |
| Emphasis | One-sentence takeaway that a broad audience can repeat |
| Display items | Few, information-dense figures; panel letters lowercase |

## Cell and the Cell Press family

| Element | Typical convention |
|---|---|
| Abstract | Summary paragraph, sometimes structured; the eTOC blurb is separate and shorter |
| Highlights | 3–4 bullets, each a finding, each very short |
| Graphical abstract | One image carrying the central message |
| Structure | Introduction → Results (with subheads) → Discussion → STAR Methods (structured) |
| STAR Methods | Mandatory structured Methods with key resources table, experimental model and subject details, method details, quantification and statistical analysis |
| References | Numbered in citation order; author lists often truncated after a set number |

## PNAS

| Element | Typical convention |
|---|---|
| Significance statement | Required, separate, ~120 words, written for a non-specialist, no citations |
| Abstract | ~250 words, unreferenced |
| Structure | Introduction → Results → Discussion → Materials and Methods |
| References | Numbered in citation order |
| Classification | A primary and optional secondary subject classification |

## PLOS (ONE, Biology, …)

| Element | Typical convention |
|---|---|
| Structure | Introduction → Materials and Methods → Results → Discussion (or Results and Discussion) |
| Abstract | Unstructured, unreferenced, no citations |
| References | Numbered **in order of first appearance**; Vancouver-style entries; DOIs encouraged |
| Figures | Cited in order; a caption file may be requested separately; colour is free |
| Style | Title case for the title, sentence case for headings; first-person allowed |
| Data | Data availability statement is mandatory; "on request" is restricted |

## Clinical and medical journals (NEJM, Lancet, JAMA family, BMJ)

| Element | Typical convention |
|---|---|
| Abstract | **Structured**, with mandated headings such as Background, Methods, Results, Conclusions; trial registration ID may be required inside the abstract |
| Reporting | CONSORT (trials), STROBE (observational), PRISMA (reviews), STARD (diagnostic accuracy), CARE (case reports) — submit the completed checklist |
| Structure | Introduction (2–3 paragraphs, no heading) → Methods → Results → Discussion (with limitations paragraph) → conclusions statement |
| References | Vancouver numbered; a hard cap on the reference count is common |
| Tables/figures | Journal-specific caps, often with a limit on the number of tables plus figures combined |

## Physical-sciences and engineering venues (IEEE, ACM, PRL, JACS, …)

| Element | Typical convention |
|---|---|
| Structure | Abstract → Introduction → Methods/Theory → Results → Discussion → Conclusion; acronym sections (e.g. related work) in computing venues |
| Abstract | Print abstract short; graphical abstract required by several chemistry journals |
| References | Numbered `[1]` or author-date depending on the society; IEEE style is numbered in citation order |
| Length | Page limits rather than word limits; over-length charges apply in some societies |
| Supplements | Extensive supplementary information is normal and expected |

## Universal checks before submission

1. Word/character count for the abstract, main text and each statement.
2. Reference count, style, and whether the venue lists all authors.
3. Figure count against the venue's cap; supplementary figures separated and numbered.
4. Whether the venue wants the Methods inline or after the references.
5. Whether the venue requires a reporting summary, significance statement, highlights, graphical
   abstract, key resources table, or checklist — these are rejection triggers when omitted.
6. Whether the venue requires the data and code availability statements to name a repository and an
   accession/DOI rather than "available on request".
7. Whether the venue requires the abstract to carry a registration number or a classification.
